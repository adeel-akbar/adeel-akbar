### 🏍️ MotoDesk — Motorcycle Shop Management System

An independently built and deployed application, delivered to a real motorcycle shop to help manage inventory, sales, and business records.

**Stack:** FastAPI · PostgreSQL · SQLAlchemy · Alembic · Next.js · Docker

**Key Features:**
- Motorcycle inventory and purchase management
- Sales tracking with profit/loss calculations and business statistics
- Downloadable PDF sales receipts

<details>
<summary><b>More features & deployment details</b></summary>

- Secure admin authentication using JWT
- Responsive frontend with PWA support
- Database migrations using Alembic
- Deployed using Docker, NGINX, HTTPS, Neon, and Cloudflare Pages

</details>
